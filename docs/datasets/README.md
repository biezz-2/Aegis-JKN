# Indeks Datasets Aegis-JKN

Folder ini memuat seluruh aset data dan literatur riset yang diekstraksi dari ruang kerja Notion **Aegis-JKN Healthkathon 2026**:

1. [01-dataset-riset-fraud-jkn.md](./01-dataset-riset-fraud-jkn.md)
   - Katalog 33 referensi riset, regulasi nasional (UU PDP No. 27/2022, Permenkes No. 24/2022), teknologi AI (MHGSL, SHAP, DP-CTGAN), dan metrik evaluasi.
   - File data: [dataset-riset-fraud-jkn.csv](./dataset-riset-fraud-jkn.csv) | [dataset-riset-fraud-jkn.json](./dataset-riset-fraud-jkn.json)
2. [02-dataset-simulasi-100-klaim.md](./02-dataset-simulasi-100-klaim.md)
   - Dokumentasi lengkap rancangan data sintetis (privacy-by-design) 100 klaim, distribusi ground truth, profil faskes, dokter, pasien, dan skenario kolusi.
3. [03-klaim-aegis-jkn-100-baris.md](./03-klaim-aegis-jkn-100-baris.md)
   - Tabel komprehensif 100 klaim sintetis beserta 27 atribut data (skor fraud, sinyal SHAP, kontradiksi narasi EMR, sentimen pasien, rujukan, biaya, dll).
   - File data: [klaim-aegis-jkn-100-baris.csv](./klaim-aegis-jkn-100-baris.csv) | [klaim-aegis-jkn-100-baris.json](./klaim-aegis-jkn-100-baris.json)
